# 2026-10-22

## 变更内容

### 全局搜索
- 新增基于编译期 JSON 索引（`themes/yinyang/layouts/index.json`，~36KB）的纯静态轻量全站搜索，零外部依赖，不产生额外运行时代价
- 新增搜索弹窗模板（`themes/yinyang/layouts/partials/search.html`），支持针对标题、分类、摘要的多词模糊匹配与关键词高亮
- 新增顶部 18×18 SVG 搜索按钮（`themes/yinyang/layouts/partials/header.html`），与明暗主题切换按钮对齐并保持统一交互质感
- 新增快捷键支持：按 `ESC` 键立即关闭搜索弹窗；点击任一搜索结果条目自动关闭弹窗并跳转
- 优化搜索索引加载策略：仅在用户首次点击搜索图标时按需异步拉取（lazy fetch），首屏初始加载完全零阻塞

### 分类系统
- 新增全站分类汇总模板（`themes/yinyang/layouts/_default/terms.html`），按文章篇数由多到少聚合展示全站所有分类
- 新增顶部导航 `Categories`（`/categories/`）入口（配置于 `hugo.toml`），精确排列在 `Home` 右侧
- 调整分类总览页点击项样式，完全对齐首页文章标题风格（`1.2rem` 字号、默认链接色、hover 仅显示下划线加粗，无外边框及背景高亮），右侧标注文章篇数 `(Count)`
- 调整分类点击项行为，点击直接直达该分类的专属归档列表页（如 `/categories/后端开发/`）
- 移除分类总览页中分类名称前面的 `#` 前缀

### 性能与静态资源
- 移除 `<head>` 中阻塞页面首次渲染的外部 FontAwesome CDN 样式文件
- 调整明暗主题切换图标为内联轻量 SVG 图标（`themes/yinyang/layouts/partials/header.html`），减少外部 HTTP 请求
- 调整公式渲染引擎，移除体积 >1.2MB 的 MathJax 3，替换为仅数十 KB 的 KaTeX（`themes/yinyang/layouts/partials/math.html`），且仅在包含公式的非首页按需加载
- 调整 Google Fonts 字体引入链接，追加 `&display=swap` 并配置 `preconnect` 预连接，消除字体加载期的文字不可见闪烁（FOIT）
- 优化首屏开场动效（`themes/yinyang/layouts/partials/loading.html`）：跳动等待时间缩短为 ~600ms，浅色背景调整为柔和浅灰（`#eaeaea`），并基于 `sessionStorage` 记录状态确保每个会话仅播放一次

### 暗色模式与主题
- 修复暗色模式在页面首次绘制时的白闪（theme flash）问题：在 `<head>` 最顶部内联执行主题检测脚本（`themes/yinyang/layouts/partials/head.html`）
- 优化 Giscus 评论区（`themes/yinyang/layouts/partials/giscus.html`）：保持英文界面，实现亮暗主题无缝动态切换，并增加服务端 session 失效自动清理重试机制
